
# LocateIT Invoice App

## Setup

1. Install Node.js
2. Open terminal in this folder
3. Run:

npm install

4. Start app:

npm run dev

## Deploy to Vercel

1. Upload project to GitHub
2. Import repository into Vercel
3. Deploy

## Features

- Firebase Integration
- Invoice Generator
- iPhone PWA Ready
- Cloud Sync Ready
- PDF Export Ready
